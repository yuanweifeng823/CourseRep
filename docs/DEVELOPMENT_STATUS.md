## 当前基础

- 已有：需求与工程约束、Docker Compose PostgreSQL 16、核心业务表迁移、Go HTTP 服务、数据库课程发现 API、认证令牌流程、课程详情与评价 API、经验帖/评论/点赞/收藏 API、评价和帖子审核决策、社区规范与处理时限配置、个人已修读课程清单。

- 当前工作目录有 Git 元数据；`mobile/android/build`、`dist` 等均为生成/构建目录，不计入功能进度。
