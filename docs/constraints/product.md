# 产品与范围约束

## 首版硬边界

首版只做港城大学课程发现、结构化评价、课程经验帖、基础互动、通知、举报和运营审核。功能范围及验收以 [`CourseRep_开发需求文档.md`](../../CourseRep_开发需求文档.md) 为准。本文件将其转化为实现约束，不另行扩张需求。

- 每个经验帖至少关联一门有效课程；年份可空，空值需被保留并展示为“年份未注明”，不得写入当前年份作为默认值。
- 评价和经验帖是不同内容类型；经验帖不得参与课程评分聚合。
- 匿名是公开展示策略，不是无作者记录。仅有权的运营治理流程可访问必要的内部关联。
- 评论仅一层；无私信、关注、非课程信息流、贡献奖励、资料兑换、交易或付费内容。
- 所有用户可见列表只返回允许展示的内容状态；审核中、拒绝、下架内容不能通过其他入口绕过状态过滤。
- 课程、标签、邮箱域名和审核策略等受管理数据必须由服务端校验，客户端选项不能视作权威来源。

## 角色与权限原则

未验证用户不能访问需求限定为校内用户的内容或互动。已验证用户可按需求浏览和参与。校友只读、停用及运营人员的具体权限必须在每条服务端路由/用例上显式校验；隐藏界面按钮不构成授权。运营权限与普通用户权限分离，并按完成任务所需的最小范围授予。

## 待决产品事项

下列事项尚未定案。实现前沿用既有行为；若没有既有行为，应将选项与影响提交产品确认或将其作为可配置策略，不得自行伪造政策：

- 年份合理历史下界、学期编码及历史课程资料的权威来源。
- 审核时限及申诉流程。
- 举报处理期限、教师相关投诉SLA、内容保留和账号处置期限。
- 隐私声明、数据保留/删除期限及适用法规下的正式合规解释。

## 首版实施裁定

以下作为首版默认产品口径，来源为 2026-11-05 项目负责人确认与本轮裁定；若产品负责人后续变更，应同步更新需求文档：

- 邮箱白名单暂限 `my.cityu.edu.hk`；验证码由负责人指定的个人邮箱临时发出，凭据仅从环境配置读取；暂不启用学号二次验证。
- 首版课程数据集暂为空，批量导入接受 CSV 与 `.xlsx`，人工校对后入库。
- 首版界面以简体中文为准。
- 帖子与评价先审后发；已发布内容仍可举报和复审。首版不提供审核模式配置开关。
- 四项评分均为 1–5 整数；概览采用有效评价算术平均值、保留一位小数；同一用户对同课程、同学期至多一条有效评价，编辑后重新审核。
- 未验证用户只访问注册/验证和必要账户设置；已验证用户可浏览互动；校友只读；停用账号禁止登录后访问。以服务端权限校验为准。
- 本地开发和验收使用 Docker Compose PostgreSQL；生产部署目标后续确定。
- 隐私正式告知、账户删除和数据保留期限仍须在公开上线前由负责人确认；这不阻止按数据最小化原则开展内部开发。
