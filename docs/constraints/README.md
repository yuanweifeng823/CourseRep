# 工程约束文档索引

本文档为需求文档的工程配套约束。所有条目服务于首版需求，不代表对应功能已经实现。

## 文档

- [产品与范围约束](product.md)：产品边界、角色、可见性和未决产品决策。
- [架构与依赖约束](architecture.md)：建议技术基线、模块边界和基础设施准入。
- [API 与数据约束](api-data.md)：接口、授权、数据模型、迁移和一致性规则。
- [安全与隐私约束](security-privacy.md)：身份、匿名、上传、日志与内容治理。
- [质量与交付约束](quality-delivery.md)：代码质量、验证、变更和交付记录。

## 适用与维护

需求文档定义用户可见行为；本目录定义实现时必须遵守的工程约束。若二者对产品行为有冲突，以需求文档为准并记录待修订项。未经明确确认的事项标注为“待决”，实现不得静默固化为不可逆产品规则。

产品范围或验收行为改变时同步更新需求文档及相关约束；选型、接口、安全约束改变时更新对应文档。文档只描述当前约定和明确建议，不声称代码已实现。决策若涉及尚未定案的外部政策，记录选项、影响和责任方，待产品确认。
