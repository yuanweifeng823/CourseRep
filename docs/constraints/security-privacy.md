# 安全与隐私约束

## 身份与访问控制

- 身份验证、邮箱白名单和账号状态均由服务端执行。访问令牌短期有效；刷新会话可撤销，登出/停用应能使会话失效。算法、过期时间、密钥轮换策略由实现配置明确。
- 使用安全密码存储方案；验证码/验证链接具备过期、单次使用和发送频率限制。认证端点需防暴力尝试和邮箱枚举。
- 每个资源操作校验主体、资源归属、账号状态和运营角色，默认拒绝。管理端操作记录操作者、对象、时间、动作和理由，不把敏感正文复制到不必要的日志。
- 最小化收集个人信息。除非确认必要且有保护方案，不收集学号；真实姓名、邮箱及身份凭据不得进入公开 API。

## 匿名与内容可见性

匿名只隐藏对普通用户的身份展示。投稿创建时保留最小内部作者关联供治理；公开 DTO、搜索索引、通知、错误信息、图片元数据及统计接口都不能旁路泄露作者。所有匿名作者关联访问需受限并可审计。禁止通过用户可控 IDOR 查询匿名作者身份。

## 图片与用户内容

- 服务端限制文件类型（检查真实内容而非仅扩展名）、大小、数量和解码资源；生成安全对象名，拒绝路径穿越和不可信远程 URL。
- 重新编码或移除 EXIF 等元数据；图片存储权限和读取 URL 按公开/受限内容策略设置。上传内容不得直接作为可执行内容提供。
- 发布提示用户遮挡姓名、学号、聊天对象等个人信息。未经核实的教师指控不得以事实形式背书；提供举报、复核、下架和处置记录流程。
- 教学资料遵守来源与版权授权要求；不实现答案买卖、代写代考服务。举报原因和处理过程只向有权限人员展示。

## 密钥、日志与数据泄露

密钥从环境变量或部署密钥管理注入，不提交仓库、不写进示例值或截图。日志默认排除访问/刷新令牌、验证码、完整邮箱、学号、身份凭据及敏感正文；需要关联排障时使用脱敏标识。错误响应不泄露内部路径、查询和秘密。生产环境强制 TLS、设置安全响应头，并限制 CORS 来源。

## 事件响应与合规待决

发现敏感数据意外公开、密钥泄漏或未授权访问时，撤销相关凭据/访问、保全必要审计信息并按组织流程升级。数据保留、用户删除请求、正式隐私告知及适用法规解释需由产品/组织负责人确认；工程文档不替代法律意见。
