# CourseRep 移动端

## 启动

```powershell
npm install
npm start
```

App 启动后先显示校内账号注册/登录流程。注册支持学生邮箱验证码，登录令牌保存在 `expo-secure-store`；访问令牌过期时尝试轮换刷新令牌。课程发现请求携带访问令牌，支持下拉刷新、按课程代码/名称/教授/专业搜索、按专业/学期筛选、按评分/评价数/分享数排序及分页加载。课程目录为空时会展示空状态。

点选课程可打开课程详情、评分概览、已审核评价和经验帖；支持评价标签、经验年份/标签/热度筛选，以及点赞、收藏和一级评论。详情中可提交匿名评价或署名/匿名经验帖、标记已修读课程，图片通过受限上传 API 提交。“我的”页面显示已修读课程、本人评价/帖子/收藏及审核状态，通知可标记已读，也可举报违规内容。

具备运营角色的账号可在“我的”页进入运营管理，分页查看并审核评价/经验帖，处理举报和课程纠错，查看指标；管理员可预览并确认课程导入、维护标签、配置内容审核时限和社区规范。审核队列不会暴露匿名作者关联信息。本人可编辑已发布或被拒的评价/帖子，保存后重新进入审核。运行 `npm run generate:api-types` 可从后端 Huma OpenAPI 文档生成移动端类型。

## API 地址

默认 Android 模拟器地址为 `http://10.0.2.2:8080`，iOS 模拟器/Web 默认用 `http://localhost:8080`。复制 `.env.example` 为 `.env` 可设置 `EXPO_PUBLIC_API_URL`。Android 真机需将地址设为开发机的局域网 IP，并确保防火墙允许 8080 端口。

后端从仓库根目录启动：`go run ./backend/cmd/courserep`，默认监听 8080。
